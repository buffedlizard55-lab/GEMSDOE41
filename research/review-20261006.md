## Pass 2 — bugs, assumptions and edge cases corrected

- **Matched mass:** bounded bisection now matches H41-A and geometry-only confidence mass as well as catalogue-density and terrain controls. Raw arms remain in the results. The gate uses matched H41-A and verifies actual mass matching, not requested mass alone. At matched mass, H41-I is worse in mean and pooled DTI. This is a protocol-correctness fix, not score-driven tuning.
- **Conditional leakage boundaries:** model construction receives only retained source geometries; training catalogue is rebuilt by rasterization of those geometries, not by deleting target pixels from a full catalogue. Withheld source IDs are disjoint and recorded. Topographic orientation is label-independent. No clipped/artificial endpoints are created. Nearby other-source duplicates are possible and explicitly measured; the 200 m exclusion is not proof all duplication has vanished.
- **Strict audit caveat:** the inherited strict protocol removes full source IDs from vector anchors but masks raster training labels by spatial block/halo, not whole source identity everywhere else. Those residual labels can affect catalogue exclusions and density controls outside the test area. We preserve the old protocol for regression only and do not call it a clean historical-best comparator. The new conditional audit avoids that pathway by rasterizing retained geometry alone.
- **Empty data:** no-truth folds are counted as unevaluable in aggregates; empty prediction folds are not dropped. A degenerate local tangent suppresses confidence. Mass-capacity shortfalls are recorded as failed matching rather than silently represented as equal-budget controls.
- **Validator optimization:** the finite export validator used Python `assert` guards, which disappear under `python -O`. It now uses explicit checks raising the same error type; regression tested under optimization. A file handle in the self-contained TIFF check was also closed correctly.
- **Previously skipped tests:** the parallel-session artifact tests looked for `example_submission.tif`, while restoration provides `sample_submission.tif`. Corrected the path and ran their actual grid and outside-footprint checks. All local tests now execute.
- **Current repository metadata:** GitHub reports `fork=false, parent=null`. Corrected IRR-01 and current pages; the inherited assertion that this is presently an organizer fork is unsupported. This does not decide prize eligibility or rights.
- **Metric and causal overstatement:** corrected IRR-04 and the parallel-session generated pages. The metric is DTI, not 1/DTI; its reciprocal algebra is `0.2 + 0.2 FP/TP + 0.8 G/TP`. Distance-weighted FP is not an unconditional 0.2 cost per pixel. The unsubstantiated assertion of cost-free deletion/masking in both organizer rounds is withdrawn. H33 is described by its owner as a prune of the reported 0.2708 base, not simply the 0.2600 file.
- **Novelty scope:** H41-I changes all 150,421 positive-cell confidence values but has the **same nonzero support as H41-A**. Support Jaccard = 1.0 versus H41-A; approximately 0.00986 versus H33. No old prediction enters construction. This is a newly computed weighting hypothesis, not new geographic coverage or proof against every private submission. The website and README state this prominently.
- **Source audit timestamp:** refreshed `audit_related_sites.py` to write its actual UTC timestamp rather than the hard-coded previous date. Permitted official-source health probes retained their TLS transport failures; content retrieval through the research tool succeeded for the papers/listing.
