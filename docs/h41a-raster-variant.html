H41-A-R: a distinct raster test of fault-transfer geometry.

This is the additional, raster-based implementation preserved from PR #8. The main site’s H41-A uses the official-source vector geometry; H41-A-R instead estimates strike families and endpoints from the 100 m competition fault raster. It is not a replacement for the main candidate.

Identifier history: before integration, this raster implementation and its dated four-quadrant protocol were called H41-A / H41-A-PRE-1 on the PR branch. The independently developed source-vector candidate on main already uses H41-A. This page uses H41-A-R to distinguish the raster implementation; the original protocol ID and thresholds are preserved in its evidence.
What it predicts

Between two structural populations—not on catalogue density.

The model skeletonizes the existing-fault raster, estimates local axial strike and coherence, classifies confident NW and N-to-NNE traces, and pairs eligible NW tips with the nearest normal-family trace within 3 km. A 500 m corridor neighborhood is scored only where the independently derived orientation proxy from detrended elevation (det_elev) agrees with the closer mapped family. Cells within 300 m of any mapped trace are excluded.

No new magnetic, gravity, thermal, conductivity, or radiometric transform is used. The regional fault-family labels are structural interpretations; the raster does not measure per-trace slip sense.

Format and validation

Valid file does not mean validated discovery.

GeoTIFF checks passed

One float32 band; EPSG:32611; 3,730 × 3,292; 100 m; exact template transform and bounds; finite in-footprint values in [0,1]; NaN outside the footprint with a NaN nodata tag. An independent re-read passed.

Spatial holdout failed

Four quadrant folds, 3.3 km collar, 7,500 target mass per fold. H41-A-R and corridor-only had zero eligible support in each test interior. The terrain-only control DTI values were 0.030317, 0.059497, 0.066946, and 0.058345; pooled 0.046888. No candidate comparison is valid.

Protocol limitation retained

The 33-pixel collar exceeds the 30-pixel tip-pair radius but is 2 pixels shorter than the 35-pixel maximum centerline-plus-support reach. No H41-A-R support entered a scored fold, but the margin remains a limitation for any future nonzero result.

The known-fault spatial holdout is only a proxy for hidden-label discovery. The owner-maintained input mirror matches its pinned hashes but is not authenticated against DrivenData’s login-gated download. No portal upload or organizer score was obtained.

Evidence: holdout report · build and uniqueness receipt · independent format audit · input/pixelwise audit · prior-raster overlap audit · three-pass review log · ranked hypotheses and preregistration.

Use only as a research artifact

The official competition page specifies a single-band float32 GeoTIFF on the supplied CRS, shape, and geotransform. Local format compliance is not a portal validation. The 300 m exclusion may also remove legitimate corrections because official staff have said valid truth can be close to existing traces.

Do not spend one of the weekly submission slots on H41-A-R: its registered support gate failed, its candidate DTI is unavailable, and there is no evidence that it beats the current spatially blocked best.
