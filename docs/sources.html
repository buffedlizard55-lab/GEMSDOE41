Input lineage

Official INGENIOUS vector bytes were fetched on a GitHub runner, archive-tested and checksum-pinned. The archive and field definitions are preserved under data/official/. Core rasters came from owner mirrors pinned to commits and SHA-256 in the input receipt. Hash equality proves mirror integrity, not organizer authentication. No prior prediction raster enters the structural model.

The trace table preserves the original source fields, including slip sense, and distinguishes geometric family from measured kinematics. The corridor GeoJSON is explicitly projected UTM11, not RFC 7946 longitude/latitude; use QGIS with EPSG:32611.
